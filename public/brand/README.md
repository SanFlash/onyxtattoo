# ONYX Brand Assets

The homepage expects the studio's supplied logo artwork at:

- `public/brand/onyx-logo.png`

Use the original ONYX Tattoo Studio artwork supplied by the owner, without redrawing, recoloring, or replacing the logo.

The page intentionally references the asset locally so the exact brand artwork can be served from both Vercel and Render without depending on a third-party image URL.
